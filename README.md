# personal-dictionary
A digital tool and repository to store, organize, and search your custom vocabulary, definitions, and personal notes.

### Backend

DICIONARY/WORD
GET /list - Get the list containing all words
GET /list/all/:id - get a specific word
POST /list/new - create a new word
DELETE /list/:id - delete a word
